# Midnight-injector
Midnight Injector a lightweight Windows x86/x64 DLL loader for offline single-player modding and development. Windows Security/SmartScreen may flag unsigned builds; verify the release and use “Run anyway” only if you trust the downloaded build.

📥 Download & Installation

Midnight Injector v1.0.0 is designed for Windows x86/x64 and offline single-player modding.

Open the Midnight Injector GitHub repository and select Releases.
Open the latest release, such as v1.0.0.
Under Assets, download Midnight-Injector-v1.0.0.zip.
Once downloaded, right-click the ZIP file and choose Extract All.
Open the extracted Midnight-Injector-v1.0.0 folder.
Run MidnightInjector.exe.
If Windows SmartScreen warns about an unsigned/unrecognized application, verify that you downloaded it from the official Midnight Injector GitHub release first. If you trust the build, you can choose More info → Run anyway.
Midnight Injector should now open. Select your offline/single-player game process, add the compatible DLL/mod you intend to use, and make sure its architecture matches the game (x64 → x64 or x86 → x86).
🛡️ Windows Security Notice

Early builds of Midnight Injector may be unsigned, so Windows SmartScreen or security software may display a warning. A warning should not automatically be assumed to be a false positive.

Only download Midnight Injector from the official GitHub repository, and don't disable Windows Security globally just to run it. For releases, you can also provide a SHA-256 checksum so users can verify that their downloaded ZIP/EXE matches the build you published.

Important: Midnight Injector is intended for offline/single-player modding and development. It isn't intended for bypassing anti-cheat systems or modifying competitive/online games.
